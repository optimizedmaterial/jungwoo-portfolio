Quasi-3D GRIN 렌즈의 수중 집속 — 유한 높이 경계효과 규명

2022–2025 · 한화오션·POSTECH·KARI 공동연구

성과: Physical Review Applied 23, 064057 (2025) 공동 제1저자 · PHONONICS 2025 발표

문제
2차원 GRIN 렌즈 설계를 유한 높이로 적층해 3차원화하면 이상화 모델에 없는 파면 왜곡이 발생 — 원인 규명과 정량 예측이 필요
설계
SUS304 원기둥 메타원자를 15층 적층한 quasi-3D GRIN 렌즈 설계
해석
밴드구조·블로흐 모드·150 kHz 등주파수면(EFC) 해석으로 이방성 파면 변환 메커니즘 규명 · 전체 구조 음압장 예측
실험
수조 음장 스캐닝으로 3차원 초점 형상 계측, 해석과 상관
정량 결과
유한 높이 경계효과가 타원형 초점을 유발함을 해석–실험 상관으로 검증 — 이상화 모델과 실제 유한 구조물의 차이를 정량 규명한 사례

광대역·광각 수중 초음파 이미징용 금속 메타물질 렌즈 — 변환광학 기반 부피 축소

2020–2022 · GIST 석사연구

성과: Mechanical Systems and Signal Processing 179, 109374 (2022) 공동 제1저자 · 석사학위논문

문제
수중 초음파 이미징용 구형 렌즈는 장착 공간 제약이 크고, 광대역·광각 성능을 동시에 만족하는 금속 구조 렌즈 설계가 필요
설계
스테인리스강(SUS304) 격자 단위구조로 구형·타원체형 렌즈 2종 설계 · 변환광학(transformation optics) 좌표 변환으로 성능을 유지하며 부피를 축소한 타원체화 수행 · 지지대 포함 3차원 조립 구조 설계
해석
밴드구조(분산선도) 계산과 S-parameter retrieval로 단위구조 유효물성 산출 · 주파수영역 음향-구조 연성 해석으로 집속 성능 예측
실험
수조에서 트랜스듀서–하이드로폰·3축 스테이지 음장 스캐닝, 해석 예측치와 정량 상관
정량 결과
구형: 80 kHz에서 FWHM 0.6λ · 타원체형: 60–160 kHz 광대역에서 초점거리 1.5λ→0λ, FWHM 0.95λ→0.59λ 확인

3차원 음향 룬버그 메타렌즈 — 격자 기둥 단위구조 설계

2019–2021 · 목포해양대 / ETRI

성과: Applied Physics Letters 118, 091902 (2021) 제1저자 · 미국특허 US 12,322,372 B2 등록

문제
전방향 음향 집속에는 굴절률이 반경 방향으로 연속 변하는 룬버그 렌즈가 필요하지만, 단일 재료 가공으로는 연속 굴절률 구배를 구현할 수 없음
설계
직경 120 mm 렌즈를 격자 기둥형 단위구조 수천 개로 이산화하고, n(r)=n₀√(2−(r/R)²)를 만족하도록 위치별 단위구조 채움률을 역산하는 파라메트릭 설계 · 면적비-굴절률 관계식 n=√(A/(A−S)) 정립(특허 청구항)
해석
COMSOL 음향-구조 연성 해석으로 단위구조별 유효 굴절률 검증 후 전체 렌즈 음압장 예측
실험
시제품 제작 후 스피커–마이크·3축 리니어 스테이지 음장 스캐닝으로 집속 성능 계측
정량 결과
5–20 kHz 광대역 전방향 집속을 실험으로 검증 · 입사각 0–180° 전 구간 일정한 음압 이득(특허 등록: 미국 1건 + 동일 패밀리 한국 1건)
